Staking & dividendes

Stakez vos ODY pour recevoir votre part des revenus réels du réseau — 80 % de chaque versement va aux stakers, au prorata du poids. Verrouiller plus longtemps augmente votre poids, jusqu'à ×2.

Contrats non configurés. Les adresses des contrats sont vides dans assets/config.js. Déployez-les (cd contracts && npm run deploy) puis reportez les adresses — voir le README du dépôt.
Aucun wallet détecté dans ce navigateur. Installez MetaMask (ou tout wallet EVM) pour staker et réclamer vos récompenses.
